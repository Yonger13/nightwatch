# ============================================================================
# Nightwatch 依赖清单
# ============================================================================
# 设计原则：**核心零依赖**。
#
# 这个项目刻意的把"必须装的东西"压到最少，原因是：
#   1. 学习者 clone 下来应该 30 秒能跑通，而不是先花半天配环境
#   2. 依赖越少，你能看懂的代码比例越高 —— 用框架搭出来的 Agent 项目，
#      90% 的代码是"胶水"，学不到东西
#   3. 面试时能说"我的主循环是自己写的，不是调的框架"
#
# 所以：下面的"可选依赖"全部不装也能跑（会自动降级到 SQLite + Mock LLM）
# ============================================================================

# --- 可选①：真实 LLM 调用 ---

httpx>=0.27.0

# --- 可选②：生产级存储 ---

# psycopg[binary]>=3.1.0
# pgvector>=0.2.5

# --- 可选③：数值计算（向量检索用）---
# 不装也能跑：会降级到纯 Python 的余弦相似度（数据量 < 1万 时够用）
# numpy>=1.26.0
